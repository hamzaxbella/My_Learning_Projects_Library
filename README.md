## Run an exercise

Choose a folder and inspect its files. For a static exercise containing `index.html`:

```bash
python3 -m http.server 8000
```

Open the corresponding folder from <http://localhost:8000>. Exercises that use a third-party API, media, or another dependency may need additional setup; there is no shared install or build command for this collection.

The repository includes learning work involving third-party designs, assets, and services. Their original rights and attribution still apply.
